# Changelog

## 1.1.0 — 2026-10-30

- Project-derived palettes, `tokens.py validate-palette` and three examples: Paper menu, Research poster and Signal board.
- Free font choice with clear criteria for readability, language support, licensing and fallbacks.
- Layout checks from 390 to 2560 px, with wide-screen and 2K+ composition rules.
- Living ASCII engine with Halftone, Grey Tiles, Braille, Amber Glow and Old Monitor, plus a three-step mount. Old Monitor supports green/warm/cool phosphor presets or any colour.
- Standalone artwork mode renamed to ASCII Artwork.
- Clearer documentation, installation guidance and MIT/CC0 licensing and font credits.

Versions 1.2–1.3.x were private pre-release builds; the public line restarted at 1.0.0.

## 1.0.0 — v1

- Interface design and implementation guidance with light and dark themes, design tokens, accessibility and visual QA.
- Living ASCII examples with authored, procedural and audio-reactive graphics, pause and reduced-motion support.
- Personal and project installation for Codex, Claude Code, Grok Build and Antigravity, with backup support for updates.
- MIT License for skill code and documentation; CC0 1.0 for the Living ASCII examples, posters and audio study.
- English and Russian documentation and reproducible ZIP packaging with SHA-256 checksums.
