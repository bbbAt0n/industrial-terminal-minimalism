# Changelog

## 1.0.0 — v1

Fresh stable distribution of Industrial Terminal Minimalism.

- Universal UI design and frontend implementation guidance with warm light and dark themes, design tokens, accessibility criteria and visual QA.
- Living ASCII Motion principles and original authored, procedural and actual-audio-reactive examples, with pause, reduced-motion and lifecycle guidance.
- Installation tooling and agent adapters for Codex, Claude Code, Grok Build and Antigravity, with personal/project scope and backed-up updates.
- Standard MIT License for project-controlled original materials; existing CC0 dedication for Living ASCII examples, posters and audio, with scoped provenance notices.
- English and Russian documentation, isolated installation validation, reproducible release packaging and SHA-256 checksums.

The established design identity, token values, implementation guidance and runtime behavior are retained. Client activation remains unverified; see adapters/verification.md.
